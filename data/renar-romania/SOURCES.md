# RENAR (Romania)

Source: RENAR accreditation certificates and annexes for the 22 bodies holding an
ISO/IEC 17021-1 accreditation (SM certificates), plus the RENAR directory listing for
phone, email and website. `proof_url` is each body's RENAR detail page.

These CSVs were generated by `romania_scraper` (from `output/pdfs` and
`output/companies.csv`). **The scraper is not in this repository yet.** Until it is
added, this dataset cannot be regenerated, only edited by hand.

Extraction rules:

- Certificate dates: `issue_date` is the renewal date (initial date when never renewed).
- Sector lists come from the "Nr. IAF" column of each annex.
- ISO 50001 / 22000 / 13485 lettered categories are classified to EA codes by sector
  and listed in `scope_note`.
- Annexes without a sector list (27001, 37001) are `ALL`.
