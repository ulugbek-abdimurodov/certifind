# ANAB (United States)

Source: ANAB (ANSI National Accreditation Board) directory of accredited management system certification bodies (ISO/IEC 17021-1), https://anabdirectory.remoteauditor.com/, with each body's Scope of Accreditation PDF (https://anab.jadian.com/Certificate.mvc). Scraped with `../database/usa/anab-usa_certifind/database/usa/scrape_us_anab.py` (`anab_raw.psv`), converted with `../database/usa/anab-usa_certifind/prepare_certifind.py`; notes, skipped schemes and pruned rows are in `anab_review.md` there. Not yet verified by a person, so `verified_at` is empty. `source_url` is the directory; `proof_url` is the scope PDF.

Extraction rules:
- One ANAB CB id is one accreditation, certificate number `MS-<id>`. `issue_date` is "accredited since", `expiry_date` the expiry in the directory.
- Accreditation standard per scheme as in the other datasets: ISO/IEC 27001/27701 → ISO/IEC 27006 (" (27006)"), ISO 50001 → ISO 50003 (" (50003)"), ISO 22000/FSSC 22000 → ISO 22003-1 (" (22000)"), ISO/IEC 20000-1 → ISO/IEC 20000-6 (" (20000)"), ISO/IEC 42001 → ISO/IEC 42006 (" (42001)"), ISO 22301 → ISO/IEC 17021-6 (" (22301)"), ISO 37001 → ISO/IEC 17021-9 (" (37001)"), ISO 55001 → ISO/IEC 17021-5 (" (55001)"), AS 9100 → AS 9104-1 (" (9104)"); everything else (ISO 9001, 14001, 45001, 13485, 37301, 28000, 15378) under ISO/IEC 17021-1.
- EA codes: ISO 9001 / 14001 / 45001 use the IAF codes from the scope PDF. ISO 22000 / FSSC 22000 categories (ISO 22003-1) and ISO 13485 main technical areas (IAF MD 8, numbered 1.1-1.7 by ANAB) are classified to EA with the ESYD tables. All other schemes (including ISO 50001, which lists no technical areas) have no sector list and are recorded for EA 1-39 with a note.
- Country from the directory address (bodies in 17 countries). Eight bodies appear only as short records without address or dates; their country was set by name. Phones rewritten to international form (US/Canada/Jamaica +1; trunk 0 dropped except Italy); extensions and second numbers dropped.
- The scrape gives ANAB id 1033 to both Emagine Compliance and Zertia USA Corp.; Zertia's record (ISO/IEC 42001 only) is skipped.
